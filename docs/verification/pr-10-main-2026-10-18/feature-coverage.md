# Feature verification coverage — PR #10 integration

This matrix describes exercised behavior and test boundaries. It is not a claim that every possible input, provider, device or future workflow was tested. All identities, records, files and request contents in automated checks are synthetic.

| Feature | Implemented checks | Evidence boundary |
| --- | --- | --- |
| Authentication and session UI | Sign-in/sign-up, SDK readiness/failure/manual retry, stationary button state, deliberate-action locking, verification/reset/MFA/invitation/session transitions | Web units and 53 isolated browser cases; actual installed Clerk lifecycle fixture plus mocked provider responses. Actual owner password/MFA and provider configuration remain separate. |
| Practice onboarding/access | Explicit founder approval, actor-owned drafts, invitations, enrollment/location assignment, current membership/permissions, origin/issuer/session enforcement | API integration/cryptographic fixtures and web/mobile unit/browser cases; no live organization provisioning or permission changes. |
| Patients | Scoped search/list/detail, contact creation/update, revision conflict, governed demographics, reload and late-response handling | Actual restricted SQL/HTTP plus UI tests; no real-patient use. |
| Scheduling/readiness | Location-calendar dates, providers/availability, overlapping visit refusal, booking/status changes, exact requirement evidence and readiness | Workflow service/database and synthetic UI cases. |
| Documents | Private upload/reservation/hash/type checks, quarantine/scan result handling, immutable versions, exact-version review/correction, access and byte delivery | Actual HTTP/file/restricted DB matrix; deterministic scanner fixtures are not a configured production scanner. |
| Forms Studio | Guided schema v2 fields/conditions/repeating sections, validation/publication, revisioned drafts, frozen submissions, PDF generation/font/page limits | Unit/service/database and builder browser cases. Arbitrary PDF overlay authoring remains unsupported. |
| Patient paperwork | One-use link/cookie scope, conditional answer sanitation, saved/frozen revisions, adult-self policy, explicit consent and signatures, retry/decline/expiry/revocation | Existing API/browser suites plus the separate real-API browser flow record. Assurance is link possession/local adult-self policy, not independent identity/certificate trust. |
| Completed-copy library | Verified account/self grant, released exact-version copies, expiry/revocation/cross-patient denial, reviewed demographic candidates and notification intents | API/service/browser cases and separate cross-layer checks. Email provider delivery/reconciliation remains gated. |
| Audit | Protected application/mutation evidence, immutable facts, reader privilege boundaries, scoped search/evidence/export and authorized transfer logs | API/restricted-database/browser checks. Independent immutable archives and retention execution remain separate. |
| Localization/layout | English/Spanish catalogs, locale/format preferences, white controls, dialogs/dropdowns, collapsed navigation and narrow screens | Catalog/shared units, web/marketing/mobile source tests and responsive browser cases. |
| Marketing | Static site/export, bilingual content, contact-validation and public-intake retry/rate/origin/failure behavior | Marketing 8 units and API intake tests. Live intake/email/operating acceptance remains separate. |
| Mobile | API/session/scope lifecycle, clinical/patient clients, language/association/release guards, lint/types, SDK compatibility and iOS/Android/web exports | Mobile 56 units, 8 association tests and synthetic preview exports. Installed binaries, physical devices, stores, verified associations and real native-provider acceptance remain open. |
| Database security/reliability | Current tenant/location/actor scopes, forced RLS/relations, immutable facts, bounded queues, timeout/disconnect/recovery and stable migrations | API 218 includes 494 HTTP requests across 12 practices / 24 locations; 36 fresh migrations/repeat/restricted catalog checks. Prior 100-practice benchmark remains October 17 evidence, not a rerun or hosted SLA. |
| Production web boundary | Preview/encoded asset blocking, private/noindex responses, nonce/CSP/transport headers and missing-association handling | Three actual HTTP tests on an owned production Next server with reserved .invalid configuration. No hosted account/session acceptance. |
| Supply chain/CI | Frozen lock graph, inherited global qs pin, backport integrity/exploit checks, YAML/fixture validation, explicit serialized builds | 16 security regressions and 1150 metadata validations pass; raw production audit still fails with 2 high findings and is not suppressed. Remote Actions runs require the user's later push. |
