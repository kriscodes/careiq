On failure, retain the last verified state and evidence; do not make a failed drill appear successful by deleting fixtures, editing the ledger or relaxing a guard.

The API disk prevents zero-downtime rollout; measure rather than assume availability. A rollback reuses the target deploy's build, startup command and service environment variables, while disks retain their current contents. Environment groups and platform configuration have different rollback behavior. Confirm auto-deploy remains off after every operation and preserve the approved secret values across all phases. Artifact retention is plan-limited; verify the fallback build is still available immediately before the drill. [Render rollback behavior](https://render.com/docs/rollbacks), [persistent-disk limits](https://render.com/docs/disks).
